# ABI Med delivery

Interactive client demonstration of medicine ordering, prescription requests, doctor appointment booking and role dashboards.

## Preview

Open `index.html` in a browser. No installation or build step is required.

## Publish with GitHub Pages

In this repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/ (root)**, then save. GitHub displays the live URL when deployment completes.

## Scope

This is a browser-only demonstration. All doctors, products, prices and providers are sample data. Orders and appointments are saved in the visitor's browser, not a shared backend. Prescription files are not uploaded; only filenames are stored. Payments, delivery locations and consultations are simulated. Use fictional data for demonstrations.

Production use requires a secure backend, authentication and role permissions, provider onboarding, payment integration, prescription storage and operational testing.
